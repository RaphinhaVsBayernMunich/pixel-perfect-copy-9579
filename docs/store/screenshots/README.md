# Genuine QuestOS Android screenshots

Captured 7 October 2026 from the existing QuestOS Android app (`app.questos.android`,
debug build versionCode 2 / versionName 1.0.0) on the existing Pixel 8 Android emulator.
The app loads the actual production Worker over HTTPS. These are direct native `screencap`
captures, not browser mockups, rebuilt HTML, generated UI or device-frame composites.

All captures: **1080×1920**, portrait **9:16**, opaque **24-bit RGB PNG**.
Only format conversion from Android RGBA to RGB is performed; no pixel color, layout, text,
cropping or dimensions are changed. Visual inspection checks readability and absence of private
inputs, emails, tokens, debugging output or sensitive personal records.

Generic sample quests were stored only in the dedicated reviewer account through normal
authenticated profile/quest writes. One was completed through the real app; statistics are computed
from that real test event, not invented performance history. No personal user account was used.
Memory remains disabled/empty; no calendar or Health Connect permission was granted for captures.

The reviewer's special one-year access was temporarily reduced, through trusted owner access,
to the normal seven-day trial label for the screenshots. Its exact original expiry is restored
after capture; no paid entitlement, receipt or client override is created. This prevents a special
review-access duration being mistaken for a consumer offer. Android System UI demo mode hides
emulator notification clutter and sets the clock; the app itself is not modified for screenshots.

Upload these files in **Grow users → Store presence → Main store listing → Graphics → Phone
screenshots**. No tablet/TV/Wear screenshots are claimed. Confirm the supported distribution
surfaces in Console before deciding whether additional genuine large-screen assets are required.

At least two phone screenshots are needed; these five meet the four high-resolution portrait
capture recommendation. [Official preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en).

Reviewer credentials remain outside the repository; never include the App access login screen
with populated fields in a store screenshot. Original private-input helpers and raw UI dumps are
ignored temporary files and are removed after this session.
