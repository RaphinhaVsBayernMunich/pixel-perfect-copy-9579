# QuestOS self-hosted fonts

Inter weights 400, 500, 600 and 700; Space Grotesk weights 500, 600 and 700.
Retrieved 7 October 2026 from the Google Fonts CSS API's published fonts.gstatic.com assets.
The stylesheet uses local URLs so rendering does not contact Google Fonts.
The corresponding SIL Open Font License texts are included from the official google/fonts
repository (`ofl/inter/OFL.txt` and `ofl/spacegrotesk/OFL.txt`). Fonts are unmodified.
